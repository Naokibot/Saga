# SEP-0001: Saga Edition 2027 Preview
Status: Implemented Preview

Introduces namespaced modules, IEEE float types, fixed-width integer boundaries, generic constraints and associated types, result/option propagation, move-only resources, structured concurrency, explicit unsafe/FFI boundaries, hygienic derive capabilities, compile-time expression functions and Diagnostics Schema 2. Each feature has Native regression tests and normative preview text. Stabilization requires cross-implementation conformance rather than Native-only behavior.
