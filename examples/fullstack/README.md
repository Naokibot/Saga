# Full-stack examples

```bash
saga run examples/fullstack/oop.saga
saga run examples/fullstack/concurrency.saga
saga run examples/fullstack/file_and_time.saga --allow-read output --allow-write output
saga run examples/fullstack/database.saga --allow-db output
saga run examples/fullstack/http_api.saga --allow-net 127.0.0.1
saga run examples/fullstack/gui.saga --allow-ui
saga run examples/fullstack/plugin/main.saga --allow-plugin examples/fullstack/plugin
```
