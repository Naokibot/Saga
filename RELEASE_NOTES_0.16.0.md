# Saga 0.16.0 release notes

0.16 focuses on portable graphics semantics, independent validation and ecosystem operations.

Highlights: SIR1 portable shader IR; second Native2 renderer path; Direct3D/Metal driver selection through target SDL renderer backends; Vulkan loader/device probe; Windows/macOS evidence harnesses; physical-controller test; second-implementation evidence; third-party lab kit; hardened TLS-capable signed package registry; starter ecosystem packages; and corrected Standard CLI exit statuses.

A Python reference `result[T,E]` checker defect discovered by the new cross-implementation suite was fixed and regression-tested.

This release does not claim Windows/macOS real-device PASS, physical controller/GPU PASS, full Vulkan swapchain support, an organizationally independent implementation, a third-party certificate, or a live public Internet registry unless separate external evidence is attached.
