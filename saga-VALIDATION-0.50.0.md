# Saga 0.50.0 validation plan — Production GA Control

The authoritative result is `validation/production-ga-0.50.0.json`, generated by `tools/production_ga_qualification_050.py` against `release/source-manifest-0.50.0.json`.

The qualification covers all 48 Python regression modules in bounded batches (506 discovered test cases), a dedicated HTTP/resource-lifecycle regression with `ResourceWarning` treated as an error, project-internal security review, specification lint, Go full tests, Go vet, Go race testing on the changed control paths, deterministic PID/FOC invariant stress, direct-native reproducibility/execution, and positive/negative machine deployment-gate binding cases.

A timeout or skipped/missing mandatory check is not converted into PASS. External target WCET, physical HIL/fieldbus/motor/drive evidence and functional-safety certification remain deployment-specific.

Qualification is resumable: every completed check is checkpointed with the exact source-manifest and source-tree hashes. If source changes, the checkpoint is ignored and the affected release must be requalified from the new frozen source.
