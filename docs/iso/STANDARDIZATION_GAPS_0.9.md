# Saga 0.9 standardization status and remaining external gates

Saga 0.9 is a technical candidate, not an ISO/IEC International Standard.

## Technical work completed in 0.9

- English normative working draft and EBNF;
- explicit conformance profiles;
- stable category codes and detailed diagnostics;
- Japanese/English learner-facing diagnostics;
- JSON schema 2 and SARIF diagnostics;
- conformance tests independent of natural-language wording;
- Python reference implementation and independent Go Standard Core second implementation;
- exact-number semantics and isolated parallel execution model;
- capability model for hosted effects;
- reproducible lock/package format;
- Unicode identifier profile and international project names;
- compatibility snapshots and migration policy;
- evidence registry and independent-lab handoff package.

## External gates that code cannot manufacture

- eligible proposer/National Body or eligible liaison sponsorship;
- nominated and consenting Project Leader;
- required P-member expert participation;
- market-relevance evidence from multiple countries and organizations;
- independent full implementation review;
- independent conformance laboratory report;
- independent security review;
- name/trademark and prior-art clearance for the name “Saga”;
- committee comments, ballots, consensus and ISO/IEC publication.

## Naming risk

“SAGA” is already used internationally for unrelated software, APIs, research systems and historical language work. Formal submission therefore requires a legal/name-confusion review and a stable standards title/identifier. This package does not claim trademark clearance.
