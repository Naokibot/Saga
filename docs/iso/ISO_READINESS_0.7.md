# Saga 0.7 ISO/IEC readiness statement

Saga 0.8.0 is a technically reviewable international-standard candidate, not an ISO/IEC standard.

## Completed technical preparation

- clause-structured working draft and normative EBNF;
- fixed Unicode 15.1 identifier profile;
- exact numeric semantics and evaluation order;
- source-unit, lock-file, and reproducible-package rules;
- task isolation memory model;
- stable diagnostic codes, JSON schema, and exit statuses;
- reference implementation and independent Portable Core Level 1 Go implementation;
- machine-readable conformance manifests and reproducible lab handoff;
- compatibility policy, governance charter, evidence registry, and implementation status.

## External gates still required

- eligible proposer and official submission route;
- named Project Leader with consent;
- participating experts from the required number of P-members;
- evidence of international market relevance and adoption;
- independent laboratory results;
- committee review, comment resolution, ballots, and publication.

No release artifact may state that Saga is ISO-certified, ISO-approved, or an International Standard before publication by ISO/IEC.
