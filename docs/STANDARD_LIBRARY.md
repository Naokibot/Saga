# Saga 標準モジュール

CLIで一覧を確認できます。

```bash
saga modules
saga modules http
```

## 内蔵モジュール

- `io`: テキスト、バイナリ、ディレクトリ
- `time`: 日付、時刻、期間
- `json`: JSON変換
- `data`: CSV、chunk、集計
- `task`: Future、スレッドプール、並列map
- `http`: HTTPクライアント・サーバー
- `net`: TCP・UDP
- `websocket`: WebSocketクライアント
- `db`: SQLiteとトランザクション
- `orm`: Sagaクラスの永続化
- `docdb`: ドキュメントDB
- `ui`: デスクトップGUI
- `crypto`: ハッシュ、認証、暗号
- `science`: ベクトル・行列・数値列
- `ml`: 小規模機械学習
- `image`: Pillow連携
- `video`: OpenCV連携
- `game`: Pygame連携
- `cloud`: クラウドSDK連携
- `gpio`: Raspberry Pi GPIO
- `machine`: PID・軌道・watchdog・安全ラッチとI²C/SPI/UART/CAN/PWM/IIO機械制御
- `spark`: PySpark連携
- `reflect`: リフレクション
- `plugin`: 権限付きPython拡張
