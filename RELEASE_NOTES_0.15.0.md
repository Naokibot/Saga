# Saga 0.15.0 — Game and Standards Readiness

Saga 0.15.0 keeps Language Edition 1.0 RC1 semantics stable and adds two optional game profiles plus Native standards-readiness tooling.

Highlights:

- 85-function Native `game` module;
- RGBA8 framebuffer, PNG/JPEG texture, animation, camera, tilemap, particles, AABB physics, WAV and asset manager;
- optional SDL2/OpenGL native desktop window/input/gamepad/audio/renderer/shader backend;
- backend-neutral `Saga Game Profile 1.0 RC1` specification and conformance vectors;
- Native `saga standards` schema-2 evidence registry aligned to current NP-stage concepts without self-certifying ISO/IEC status;
- explicit game resource limits and native-host dependency disclosure;
- new portable and desktop game integration examples.

This is a project release candidate ecosystem, not an International Standard or independent certification.
